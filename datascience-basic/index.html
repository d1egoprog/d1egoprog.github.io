The starting point

Good research starts
with understanding your data

This course brings together the foundations of data science and the practical work of data management. We begin with a research question, examine the data behind it, and explore how analysis can support a defensible interpretation.

You will work with data formats, cleaning decisions, introductory AI, and text analysis. Documentation, visualization, and responsible reuse run through the course.

What you will practice

  • Describe a dataset, its origin, and its limitations.
  • Recognize common formats and prepare data for analysis.
  • Explain the purpose of a model and how to evaluate it.
  • Communicate a simple analysis with a clear chart and reproducible steps.

Before you begin: bring basic computer skills, an interest in research, and a willingness to experiment. The practical work introduces Python and notebooks step by step.

A quick reference

A few ideas to keep close

Short explanations of the concepts we will return to throughout the course.

01Data & metadata

Data records observations. Metadata explains those observations: what a variable means, its units, where it came from, and how it was collected.

A value of 42 needs a variable name and a unit to be useful.

02Data structure

Tables follow a predefined schema. JSON and XML organize semi-structured records. Text, images, and audio need other methods to extract useful features.

A survey table and its free-text responses need different preparation.

03ETL & data quality

Extract data from a source, transform it into a consistent form, then load it for use. Inspect missing values, duplicates, units, and unexpected values along the way.

Keep the raw file and record each change in a cleaning log.

04Descriptive & predictive analysis

Descriptive analysis summarizes what you observed. Predictive analysis learns patterns to estimate outcomes for new observations and needs evaluation on unseen data.

Summarizing past counts and predicting a future count answer different questions.

05FAIR research data

Findable, Accessible, Interoperable, Reusable. Useful metadata, clear access conditions, shared formats, and explicit reuse conditions help others work with your data.

Package a dataset with a data dictionary, its origin, and a license.

06Text as data

A corpus is a collection of documents. Tokenization splits text into units. A bag of words counts terms while leaving out word order and much of the context.

Removing “not” can change the meaning of “not good”.

Look inside a file

Same observations.
Different formats.

These two fictional sample records hold the same information. The format changes how you read and organize it.

CSV+

A table with a header and one record per row. Check the delimiter and encoding when importing.

sample_id,site,count
S01,North,12
S02,South,9
JSON+

Objects and arrays can express nested records. JSON keys and string values use double quotes.

[
  {"sample_id": "S01", "site": "North", "count": 12},
  {"sample_id": "S02", "site": "South", "count": 9}
]
XML+

Named tags describe elements and their hierarchy. Each record contains the same observations as the CSV and JSON examples.

<samples>
  <sample id="S01"><site>North</site><count>12</count></sample>
  <sample id="S02"><site>South</site><count>9</count></sample>
</samples>

Learning by doing

Put the concepts to work

Use a small dataset you are allowed to work with. Keep a record of your choices as you go.

  1. 01

    Inspect a file

    Compare the CSV, DSV, JSON, and XML examples. Identify the records, fields, delimiter, and encoding. Write down what you can and cannot infer from the file alone.

    File examples ↗
    EXPLORE
  2. 02

    Prepare a reusable dataset

    Inspect missing values, duplicates, and inconsistent labels. Preserve the original file and document your changes. Add a data dictionary, a short README, and clear access and reuse conditions.

    Keep: a CSV, its documentation, and a cleaning log.

    PREPARE
  3. 03

    Take text from a DSV file to a chart

    Use a Python notebook to load a text column with pandas. Inspect and tokenize the text, compare stopword choices, and count terms. Plot the frequencies and explain the limits of that representation.

    Python + NLP practice ↗
    ANALYZE

Before sharing your results

Can another researcher understand the variables, follow your steps, and explain the limitations? Describe how you handled privacy and permission to use the data. Give each chart a clear title, labelled axes, and units where relevant.
